# Asset guide
Place your own files here. Filenames must match exactly. Missing images show a labeled placeholder.

| Folder | Filename expected | Used on | Suggested size |
|---|---|---|---|
| images/logo/ | camngo-logo.png | Header (hidden if missing) | ~200x72, transparent PNG |
| images/cameras/ | canon-sx740.jpg | Home, Cameras | 1200x900 (4:3) |
| images/banners/ | hero-banner.jpg | Home hero | 1200x900 (4:3) |
| images/icons/ | (none yet) | Reserved | SVG/PNG |

To add a camera later: add a photo to images/cameras/, then add an entry to the CAMERAS array at the top of js/main.js.
